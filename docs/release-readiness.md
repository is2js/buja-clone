# 공개 배포와 유지보수 단계

점검일: 2026-11-07. 배포 대상은 `github-pages-public-v1` 지도·3D 공개판이다. 로컬 실거래 자료는 공개 대상이 아니다.

`npm run build:pages`가 프로젝트 하위 경로로 빌드하고, 명시적으로 허용한 파일만 공개 후보에 넣은 뒤 `npm run check:release`를 실행한다. 점검표는 이 공개 프로필에만 적용된다. 검사는 실제 공개 후보의 실거래 제외, 독립 경계 출처, GTX 공개 좌표와 ODbL 표시도 확인한다. 전체 로컬 자료의 공개 권한을 승인하는 검사가 아니다. 후보의 실제 경로는 `work/pages-output.json`에 기록되며 워크플로도 이 경로만 게시한다. 기존 폴더가 잠겨 있으면 완성된 별도 후보를 사용한다.

`.github/workflows/pages.yml`은 수동 실행만 허용한다. 코드 push만으로 반복 실행하지 않으며 다른 저장소의 중지된 Actions를 재개하지 않는다. 브이월드 키를 GitHub Secrets나 Vite 환경 변수로 전달하지 않는다.

## 공개판에서 해결하거나 제외한 자료

- `public/data/geo.json`은 고정된 SGIS/vuski 원천에서 독립 재생성했다. 16개 시도·256개 시군구·3,559개 행정동의 코드·이름을 유지하고 3,815개 구·동 경로의 변환을 검사했다. 부자 중간 가공물과 역 매핑은 포함하지 않는다. [출처와 제한](../public/data/SOURCES.md)
- 실거래는 계약일 기준 수동 스냅샷으로 로컬에 보존하고 공개 소스·산출물에서 제외한다. 공개판은 빈 메타데이터와 데이터 없음으로 표시하며, 향후 공식통계나 조건을 확인한 독립 수집 자료를 연결한다. KRIC 좌표 2곳도 재사용 조건 확인 전 공개판에서 생략한다. [공개 프로필](pages-data-profile.md)
- OSM 자료의 ODbL과 타일 제공자의 정책·호출량을 확인하고 출처를 표시한다. 공용 타일 서버는 SLA가 없으므로 공개 규모에 맞는 제공자를 별도로 정한다. [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/)
- 원본과 제휴하지 않은 학습용 프로젝트라는 안내를 화면에 표시한다. 안내만으로 원본 가공물의 재배포 권한이 생기는 것은 아니다. [GitHub Pages 학습용 복제 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

## 운영 구조

- `.env.local`의 브이월드 개발키와 로컬 Vite 프록시는 정적 Pages에 포함하지 않는다. Pages의 실시간 브이월드 건물 조회에는 제공자의 운영 승인과 도메인 등록, 접근 제한·호출량 제한·장애 감시가 있는 별도 서버가 필요하다. 그 전에는 정적 OSM 자료로 작동한다. [키·배포 안내](vworld-pages.md)
- 원천별 기준일과 수집 결과, 데이터 버전, 결측·미연계 및 실패를 기록한다. 자료 갱신은 검증한 버전을 완성한 뒤 교체하며, 실거래는 신고 지연과 정정·해제를 재수집한다. 브이월드 만료 경고는 로컬 서버 시작이나 페이지 로드 시에만 표시되며 별도 알림은 없다.
- 실제 공개 전 지역 표본의 경계·시세·건물과 선택 상태, 모바일 보행 성능, API 장애 시 대체 동작, 접근성 및 제공기관의 저장·캐시·재배포 조건을 검토한다.

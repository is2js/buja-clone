# 법정동·행정동 기준과 자료 출처

## 기준

- 전국 현존 법정 읍·면·동 목록: [행정표준코드관리시스템 법정동 코드 전체자료](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010). 2026-11-04 한국시간에 코드 전체자료 ZIP을 직접 내려받아 `존재` 항목 중 읍·면·동만 추출했습니다. 생성 시 스크립트 `scripts/generate-legal.py`에 획득 경로를 기록합니다. 리·폐지코드·상위 시군구 코드는 동 목록에서 제외합니다. 전국 선택 UI에 사용합니다.
- 법정 경계: [KnellBalm/kr-admin-geojson](https://github.com/KnellBalm/kr-admin-geojson)의 `emd.geojson` 전국에서 코드가 연결되는 경계를 사용합니다. 원천은 **국가공간정보포털(V-World) 2023-07-29 배포 경계**, 중간 가공자가 단순화 및 EPSG:4326 변환했습니다. README의 이용 조건은 출처표시입니다. 이 프로젝트는 좌표를 앱 지도 좌표로 다시 투영하고 소수점을 줄였습니다.
- 다음 생성부터 경계 원천을 커밋 `3a859f2a45be8acf8237d9eefd9565f99cc603da`로 고정하고 파일 SHA-256을 검증합니다. 제공처가 설명하는 원천 경계 기준일과 저장소 커밋은 서로 다릅니다. 과거 생성한 `legal.json`의 정확한 커밋·해시는 기록되어 있지 않으므로 소급 확정하지 않습니다. 새 버전으로 갱신할 때 README의 원천 기준일·이용 조건 및 해시를 함께 검토해야 합니다.
- 코드 목록과 경계는 기준 시점이 다릅니다. 2023년 이후의 경계·행정구역 변경을 반영하지 못할 수 있습니다. 원본 앱의 시군구 경계도 시점·축척이 달라 서로 어긋날 수 있습니다. 법정동 코드는 같아도 경계가 최신이라고 보장하지 않습니다. 특정·측량·정밀 공간 판단에 사용하면 안 됩니다.
- 현존 코드의 앞 8자리가 경계의 EMD 코드와 일치하면 도형을 사용합니다. 전북은 2024년 45→52 코드 변경과 지명 일치를 확인합니다. 인천과 전남광주는 [행정안전부 2026-07-01 변경 전후 상세표](https://mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=127039)의 법정동 코드가 유일하게 연결되고 지명도 일치하는 경우에만 2023년 경계를 연결합니다. 이 변환은 코드 대응이며 이후의 경계 변동까지 보장하지 않습니다. 경계를 확보하지 못한 법정동은 상위 시군구만 표시하고 `경계 확보 안 됨`을 안내합니다. 다른 행정동의 모양을 임의 대입하지 않습니다.
- [성남시사](https://www.seongnam.go.kr/contents/down/History/HistoryOfSeongnamCity_10.pdf)는 동원동이 구미1동 관할임을 기술하나 2014년 자료입니다. 최근의 공적 매핑을 아직 독립 검증하지 않았으므로 목록과 지도에서는 두 경계를 하나로 합치지 않고 각각 표시합니다. 코드 `4113511300`은 이번 공식 다운로드의 현존 법정동 목록에서 확인했습니다.

## 표시와 추가 확보

행정동·법정동은 서로 다른 공간 단위이며 이름 유사성이나 행정동-법정동 간 1:1을 전제하지 않습니다. 같은 이름이라도 타입을 구분합니다. 법정동 실거래는 해당 법정동 코드로 확인한 경우에만 연결하며, 행정동 결과로 전용하거나 다른 동의 숫자로 대체하지 않습니다.

행정동 원천은 별도로 `public/data/SOURCES.md`를 참조하세요. 2023 이후의 새로운 법정 경계는 [국토부 법정구역 서비스](https://www.data.go.kr/data/15123903/openapi.do) 또는 각 지자체 공개 자료의 최신성과 이용 조건을 검토한 뒤 교체해야 합니다. 서비스 신청·API 키가 필요한 방식은 이번 정적 프로토타입의 자동 갱신 경로가 아닙니다.


## 2026-11-04 정합성 보정

법정동 생성 시 동·읍·면·가라는 이름 접미사나 3단어 이상이라는 조건으로 유형을 판단해 서울 세종로, 대구 시장북로·남성로, 세종특별자치시 직속 동·읍·면 33개가 누락되는 오류를 수정했습니다. 현존 10자리 코드 구조로 상위 코드와 리를 구분합니다. 2023년 경계와 코드가 일치한다고 현재 경계까지 검증된 것은 아닙니다. `node scripts/check-data.mjs`로 자료의 기준일과 지역 집계 정합성을 확인합니다.

2026-11-04 전국 확장 결과 현재 법정 읍면동 코드 5,067곳 중 4,998곳에 과거 경계가 연결됩니다. 연결되지 않은 69곳은 도형을 대신 만들지 않습니다. 지도에는 2023년 이후 행정구역 변동이 반영되지 않았을 수 있습니다.

# 보행망과 추정 경사

검토일: 2026-11-05. 서울·하남 경계 상자(동경 126.75~127.32도, 북위 37.40~37.75도)에 포함된 [Geofabrik 대한민국 OSM 추출본](https://download.geofabrik.de/asia/south-korea.html)을 사용한다. 이 네트워크는 © OpenStreetMap 기여자, [ODbL 1.0](https://www.openstreetmap.org/copyright)이며 가공 데이터에도 동일한 출처와 라이선스를 적용한다. 이 경계 상자는 서울·하남 행정구역과 정확히 일치하지 않으며 OSM에 기록되지 않은 구간은 경로에 포함되지 않는다.

자동차 전용 도로, 통행금지·사유지 등과 확인할 수 없는 조건부 통행제한은 제외하고, 같은 OSM 노드 ID를 공유하는 지점만 교차로로 연결한다. 서로 교차해 보이지만 다른 노드인 도로를 임의로 합치지 않는다. `oneway:foot`을 보행 방향으로 반영한다. 실제 도로 통행 여부, 공사, 출입문·계단, 교량, 현장 접근성과 최신성은 보장하지 않는다. 지도의 단지 위치는 출입구가 아닐 수 있다.

시작·도착점을 연결할 때 보행 그래프에 가장 가까운 **선분**을 찾아 50m 미만인 경우에만 연결한다. 그 거리는 별도 표시하고, 경로 길이에는 보행망에 연결되기 전의 거리를 포함하지 않는다. 실제 출입구나 보행 가능 경로를 보장하는 내비게이션이 아니다. 끊어진 그래프·고도 결측은 각각 안내하며 경로를 직선으로 임의 연결하거나 결측 고도를 0으로 처리하지 않는다.

고도는 Terrain Tiles Terrarium 자료를 보간한 결과이고, 경로를 약 30m 간격으로 최대 1,000점 표본화하여 3점 이동 평균으로 완화한 뒤 고도차/거리×100으로 경사율을 계산한다. 긴 경로의 표본 간격은 30m보다 넓어질 수 있다. 전역 DEM은 약 30m급 원자료를 포함하지만 지역별 실제 해상도·정확도가 보장되지 않으며 계단·축대·교량 상판·개별 건물 출입구의 미세 경사와 실제 통행로를 반영하지 못한다. 세 구간 이동 평균도 적용하며 고도 상승·하강은 평활된 표본을 기준으로 산출한다. 따라서 출력은 **저해상도 참고 추정치**이다.

그래프는 약 48 MB(압축 전)이며 보행 경로를 처음 계산할 때만 내려받아 작업자 스레드 메모리에 보관한다. 경로 탐색과 간선 공간 인덱스 생성을 작업자 스레드에서 수행하고, 시작·도착점이 시범 범위 밖이면 큰 파일을 받기 전에 안내한다. 고도 이미지는 브라우저에서 별도로 읽는다. 지역별 파일 분할은 아직 적용하지 않았으므로 모바일에서는 최초 다운로드와 메모리 사용에 시간이 걸릴 수 있다. 경로 계산 중 시도를 바꾸거나 지점을 변경하면 이전 결과는 화면에 반영하지 않는다.

## 갱신

1. Geofabrik 대한민국 OSM PBF 파일을 내려받아 `work/route-input/south-korea-latest.osm.pbf`에 둔다. 다운로드 날짜와 파일의 기준일(서버 Last-Modified 또는 extract 메타데이터)을 확인한다.
2. 빌드 전용 환경에 `python -m pip install osmium`을 설치한다. 이 라이브러리는 서비스 런타임에 필요하지 않다.
3. `python scripts/build-walking-graph.py work/route-input/south-korea-latest.osm.pbf --as-of YYYY-MM-DD`를 실행한다. 데이터는 `public/data/walking/seoul-hanam.json`에 원자적으로 생성하며, 지나치게 적은 결과는 기존 파일을 보존한다. 원본 파일은 git에 포함하지 않는다.
4. `node --test test/walking.test.js`와 `npm run build`를 실행하고, 단절·50m 초과·고도 실패 및 실제 도로 몇 곳을 확인한다.

서울시 [자치구별 도보 네트워크](https://data.seoul.go.kr/dataList/OA-21208/S/1/datasetView.do)는 공공누리 1유형이지만 조사 시 공개 파일 목록에 표시된 항목은 유형 코드표뿐이었다. 전체 공간 네트워크를 무키로 확보할 수 있는 경로와 정확도는 추가 검증이 필요하다.

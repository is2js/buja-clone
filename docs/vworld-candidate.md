# 브이월드 건물 후보 자료 준비

이 도구는 **API를 호출하거나 키를 읽지 않는다.** 브이월드의 실제 조회·사용 조건·응답 형식과 필드 확인 전 단계에서 사용자 소유의 GeoJSON 샘플을 로컬에서 검토하도록 돕는다. 후보 자료는 지도에 자동 연결되거나 공개되지 않는다. 현재 사이트는 로컬 개발 서버에서만 브이월드 건물과 배경을 조회하고, 정적 배포에서는 OSM을 사용한다.

1. 허가된 경로로 확인한 **WGS84 경도·위도**의 GeoJSON `FeatureCollection` 샘플을 준비한다. WFS 응답에 다른 좌표계가 지정된 경우 좌표 변환을 먼저 수행한다. GeoJSON이 아닌 XML 및 중첩 JSON 응답은 이 도구에서 읽지 않는다.
2. 실제 제공자가 반환한 필드의 뜻과 단위를 확인한다. 건물 ID와 건물별 높이(m) 또는 지상 층수를 확인할 수 없으면 표시하지 않는다. 다른 건물이나 필지의 높이를 대신 붙이지 않는다.
3. 다음 예시에서 `실제_ID_필드` 등은 **실제 데이터의 필드명으로 교체해야 하는 자리 표시자**다. 아래 이름이 브이월드의 실제 필드명이라는 뜻이 아니다.

   ```powershell
   python scripts/prepare-vworld-candidate.py C:\path\to\sample.geojson `
     --confirm-wgs84 --as-of 2026-11-05 --output candidate.geojson `
     --id-field 실제_ID_필드 --name-field 실제_건물명_필드 `
     --height-field 실제_높이_m_필드 --levels-field 실제_지상층수_필드
   ```

   ID가 GeoJSON의 `feature.id`에 있다면 `--id-field`는 생략한다. 이름 필드는 선택사항이며, 높이와 층수 필드 중 실제로 확인한 것만 지정할 수 있다. 기준일은 실제 샘플의 기준일로 바꾼다.
4. `work/vworld-candidate/`에 같은 이름의 파일이 없다면 새 후보 파일을 만든다. 폴더는 `.gitignore`에 포함된다. 이 후보는 필드·좌표·범위·중복을 직접 검토하고, 자료별 저장·가공·재배포 조건을 확인하기 전까지 프로젝트의 `public/`에 복사하거나 배포하지 않는다.

변환기는 도형의 좌표 범위와 고리 폐합을 검사한다. 유효한 높이가 없으면 유효한 층수 × 3m를 사용하고 추정값임을 기록하며, 둘 다 없으면 제외한다. 원천 ID가 누락되거나 중복되면 중단한다. 다른 원천 속성은 복사하지 않는다. 이 검사는 실제 건물 위치·높이의 정확성, 단지별 연결, 폴리곤의 완전한 기하학적 유효성 또는 재배포 권리를 보증하지 않는다.

독립 검증: `python -m unittest discover -s test -p 'vworld_candidate_test.py' -v`. 실제 API의 응답·필드·인가를 검증하는 테스트는 아니다. 이 도구는 사이트의 로컬 실시간 연동과 별개다. 정적 자료를 공개하려면 제공 조건과 데이터 접근 방법을 확인하고 별도의 검증이 필요하다.

# 전국 아파트 단지 정적 자료

확인일 2026-11-05. 원본은 한국부동산원의 공공데이터포털 [단지 기본정보](https://www.data.go.kr/data/15106861/fileData.do)와 [동정보](https://www.data.go.kr/data/15106866/fileData.do) 파일이다. 두 파일명에 적힌 날짜는 2026-08-31이며 포털 수정일은 2026-09-01이다. 제공기관은 해당 연도 파일이 전년도 사용승인된 공시 대상 공동주택을 기준으로 하며, 공시가격 DB와 건축물대장·도로명주소 DB의 시점 차이 및 미매칭으로 일부 칸이 비어 있을 수 있다고 설명한다. 따라서 현재 모든 단지나 최신 입주 현황을 보장하지 않는다.

공공데이터포털의 두 파일별 메타데이터는 **이용허락범위 제한 없음**을 명시한다. 단지종류 코드가 `1`인 아파트만 선택했고 연립(`2`)과 다세대(`3`)는 제외했다. 단지고유번호를 사용해 동정보를 결합했고, 단지명은 공시가격·건축물대장·도로명주소 순으로 이용 가능한 값을 표시한다. 단지 ID가 중복되거나 필수 열이 없으면 생성이 중단된다.

기본정보는 공개 단지 ID·단지명·주소·필지고유번호·건물 동수·세대수·사용승인일을 포함하며 동정보는 동명·지상층수를 포함한다. 제공된 자료에는 소유자·거주자 이름, 연락처, 개별 세대 거래 내역이 없고 인덱스에도 추가하지 않는다. 단지 주소와 필지 식별자는 공개 자료지만 정밀 위치와 연결될 수 있으므로 신규 데이터 결합 및 외부 공개 시 재식별 가능성과 제공기관의 최신 안내를 다시 검토한다.

## 결과와 이용 방법

- `public/data/real/apartments/index.json`: 전국 아파트 46,385건의 `{id,name,address,area}` 검색 인덱스. 검색 시 지연 로딩하며 파일 크기는 약 5.5MB다.
- `public/data/real/apartments/{시도코드}.json`: 지역별 기본정보와 동정보. 서울 9,528건, 경기 8,491건, 인천 2,261건 등 16개 화면 시도 그룹으로 나눈다.
- `sourceLegalCode`와 `sourceParcelCode`는 원천 파일의 PNU 앞부분과 원문을 기록한다. 행정구역 개편 이전 코드가 포함될 수 있어 이를 현재 법정동 경계에 검증 없이 연결하지 않는다. 전남·광주의 과거 PNU 코드는 화면의 전남광주 그룹 `12`에 묶지만 원본 PNU는 유지한다.
- 원천 CSV는 좌표와 건물 외곽 도형을 제공하지 않는다. 따라서 실제 단지의 `coordinate`와 `geometry`는 모두 `null`이며, 지도에서 실제 위치처럼 표시해서는 안 된다. 위치와 도형을 확보하려면 공식 공간자료의 코드·기준시점·정확도·이용 조건을 별도 확인해야 한다. 동정보의 층수만으로 건물 모양이나 위치는 알 수 없다.

## 갱신

1. 위 공식 파일 화면에서 각각 기본정보와 동정보 전체 CSV를 내려받아 작업용 폴더에 `basic.csv`, `buildings.csv`로 저장한다. 원본 파일은 정적 공개 폴더에 넣지 않는다.
2. 프로젝트 루트에서 `python scripts/build-apartment-index.py <CSV 폴더> --as-of YYYY-MM-DD`를 실행한다. 날짜에는 파일명 기준일을 입력한다. CSV는 CP949 형식이며 필수 열과 중복 ID, 예상 최소 건수 및 지역 수를 검사한다.
3. 검색 인덱스와 각 지역 파일은 임시 파일을 거쳐 교체한다. 수집 날짜와 공시 자료의 대상 연도, 원천 누락·행정코드 변경, 공개 자료 제공조건을 검토한 뒤 배포 여부를 결정한다.

단지 목록은 임장지도 사이트의 가공 목록을 사용하지 않는다. 아파트 단지별 실거래, 좌표·형상, 현재 통행 가능 여부, 경사도는 이 파일에서 계산할 수 없다.


## 서울시 대표 좌표 (2026-11-05 수집)

서울시 [공동주택 아파트 정보 OA-15818](https://data.seoul.go.kr/dataList/OA-15818/S/1/datasetView.do) 전체 Sheet CSV를 공식 파일 생성 경로로 수집했다. 공공누리 제1유형(출처표시)이며, 표본 갱신 시점을 각 단지의 실제 조사일로 간주하지 않는다. `python scripts/build-seoul-apartments.py --as-of YYYY-MM-DD`로 `public/data/real/apartments/seoul-locations.json`을 다시 생성한다. 다운로드나 필수 필드 검증 실패 또는 예기치 않게 적은 건수일 경우 기존 파일을 보존한다. `--csv`로 별도 확보한 원본을 사용할 수 있다.

전수 2,896건 중 2,856건의 좌표가 서울 광역 범위 검사에 통과하고 40건은 결측·범위 밖이어서 지도에 표시하지 않는다. 소수점 6자리 기준 42개 좌표 그룹 88건이 중복되며 위치를 임의 보정하지 않는다. 이는 **좌표 형식과 광역 범위 검사**에 불과하고, 단지 위치 정확도나 출입구를 보장하지 않는다. 원본의 아파트와 주상복합 등의 유형을 유지하고, 전화·팩스·소유자·연락처는 결과에 넣지 않는다.

한국부동산원 원본 서울 단지와의 매칭은 NFKC 정규화와 공백 제거 외에 추측을 하지 않고 단지명과 서울시·구를 포함한 전체 도로명주소가 양쪽에서 유일하게 일치할 때만 수행한다. 733쌍 중 718쌍이 서울 좌표 범위 검사를 통과했다. 연결되지 않은 서울시 항목은 원천 ID `seoul:...`로 독립 표시하며, 서로 다른 원천의 ID를 동일시하지 않는다. 해당 건의 위치 출처·수집일·중복 여부를 유지한다.

경기도 하남 자료는 아래와 같이 추가했으며 다른 지자체 자료는 별도 다운로드·좌표/유형·이용조건 확인이 필요하다. 실거래는 지역 통계일 뿐 단지 개별 거래로 연결하지 않는다.

## 하남시 대표 좌표 (2026-09-01 자료)

[경기도 하남시 공동주택 현황](https://www.data.go.kr/data/3047304/fileData.do)은 이용허락범위 제한 없음이다. 공식 다운로드 절차로 확보한 135개 중 135개의 좌표가 하남시 광역 범위 검사에 통과했고, 1개 좌표에 2개 단지가 중복된다. 주소·이름·주택유형·좌표·세대수·사용검사일만 사용하며 전화·팩스는 저장하지 않는다. 이 검사는 현장 위치·출입구 확인이 아니다.

`python scripts/build-hanam-apartments.py --as-of YYYY-MM-DD`로 갱신한다. 원본 날짜를 확인해 명시해야 하며 `--csv`로 수동 다운로드 파일도 사용할 수 있다. 파일명 기준일 기본값은 2026-09-01이고, 제공처가 CAPTCHA를 요구하면 우회하지 않고 기존 결과를 보존한다. 원천은 지번주소이므로 서울 자료처럼 동일한 도로명주소를 통한 일치 검증이 불가능하다. 주소·단지명에서 생성한 독립 `hanam:` ID로 관리하고 한국부동산원 데이터와 자동 병합하지 않는다.


## 달서구·광산구 좌표 (지자체 공개자료)

[대구 달서구 아파트 현황](https://www.data.go.kr/data/15054183/fileData.do) 2026-09-09 자료 439개 행 모두 대구 광역 범위 좌표 검사를 통과했으며, 이 중 190개가 한국부동산원 단지와 이름·전체 도로명주소의 양방향 유일 일치다. 중복 좌표는 7그룹 14행이다. 갱신: `python scripts/build-local-apartments.py dalseo --as-of YYYY-MM-DD`.

[전남광주 광산구 공동주택 현황](https://www.data.go.kr/data/15100132/fileData.do) 2026-04-02 자료 334개 행 모두 광주 광역 범위 좌표 검사를 통과했다. 같은 이름·주소라도 승인일·동수가 다른 28개 원본 행은 누락하지 않고 보존한다. 따라서 원본의 행 수가 실제 단지 수와 일치한다고 보장하지 않으며, 화면은 동·단지 구분 미확인으로 표시한다. 중복 좌표는 32그룹 68행이다. 갱신: `python scripts/build-local-apartments.py gwangsan --as-of YYYY-MM-DD`.

두 원천 모두 이용허락범위 제한 없음이다. 파일 기준일과 명시한 --as-of를 대조하며 CAPTCHA나 검증 실패 때 기존 JSON을 보존한다. 전화번호·관리 연락처·인구수는 결과에 포함하지 않는다. 좌표 광역 범위 검사는 정밀 위치나 단지 출입구 확인이 아니다.

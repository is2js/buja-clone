# 임장 지도와 실제 자료

검토일: 2026-11-05. 기존 점수 지도에서 실제 단지·지형과 보행 경사를 선택한다. API 키와 백엔드는 필요하지 않다.

## 실제 자료

- 서울시·하남시·대구 달서구·광주 광산구 공개 공동주택 자료의 대표 좌표를 점과 묶음으로 표시한다. 광산구 원천 행은 단지 또는 건물 단위인지 확인되지 않아 행을 보존한다. 좌표의 행정구역 범위 검사는 위치의 정밀도나 실제 출입구를 보증하지 않는다. 좌표가 없거나 범위를 벗어난 항목은 검색만 가능하고, 한 좌표의 여러 원본 항목은 위치를 임의로 이동시키지 않는다. 유형·기준일·출처 및 연결 방식은 [단지 자료](apartment-sources.md)를 참조한다.
- 한국부동산원 전국 단지 정보에는 별도로 검증된 좌표가 없는 경우 검색만 제공한다. 서울시 자료와 유일한 이름·전체 도로명주소가 정확하게 일치하는 경우에만 연결하며, 양쪽 원본 ID를 별도로 보존한다. 단지별 거래나 실측 건물 형상은 없다.
- 실제 모드의 2D 음영과 3D 지형은 [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)의 Terrarium 타일을 현재 화면 범위에서 읽는다. 글로벌 DEM에는 약 30m급 원천 자료가 포함되지만 지역별 정확도는 보장되지 않는다. 계단·축대·교량 등의 세부 지형을 나타내지 못하며 실패 시 기본 2D 지도를 사용할 수 있다.
- 서울·하남 시범 보행망은 OpenStreetMap의 Geofabrik 추출본을 기반으로 한다. 50m 미만으로 연결 가능한 경우에만 경로를 만들고 고도 표본으로 참고 경사를 계산한다. © OpenStreetMap 기여자 · ODbL. 추출 범위, 경로 연결, 고도 결측, 갱신 절차와 주의점은 [보행망과 추정 경사](walking-data.md)를 참조한다.
- 실제 3D 건물은 전국 OSM 대한민국 추출본에서 외곽과 높이 또는 층수가 기재된 건물만 표시한다. 외곽·높이는 현장 실측을 보장하지 않으며 지역별 누락이 많을 수 있다. 건물은 대표 단지와 자동 연결하지 않는다. [건물 자료·갱신 절차](buildings-data.md)를 참조한다.
- 원본 임장 사이트의 고해상도 5m 자료와 본 프로젝트의 공개 글로벌 DEM은 별도 자료다. 원본 가공 단지·지형·경로 데이터는 재배포하지 않는다.

## 예시 모드와 후속 단계

`가상 예시`에서만 `public/data/sample-3d.json`의 가상 단지와 지형 및 돌출 건물을 표시한다. 실제 모드에서는 OSM 외곽과 높이·층수가 있는 건물만 별도 레이어로 표시한다. 건물과 단지의 공식 일치 여부를 판단하지 않으며 해당 정보가 없는 단지는 마커만 제공한다. 점수와 GTX 개략도는 기존 지역 데이터와 출처를 유지하며 2D/3D의 중심과 확대 수준을 공유한다.

추가 지역은 공식 단지 좌표와 보행망의 단위·권리·기준일을 확인한 뒤 갱신한다. 실제 거래나 공식 건물 자료, 인증키가 필요한 고해상도 자료 및 자동 수집·FastAPI는 별도 단계에서 검토한다. 지도 타일 이용량과 배포 정책을 확인하고 대량 사전 다운로드는 하지 않는다.
